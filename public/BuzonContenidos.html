¿Como funciona la pagina?

Sigue estos pasos para generar el informe. Tu progreso se conserva si recargas la pagina y solo se borra cuando usas "Borrar archivo".

  1. Agregar contenido: elige tipo, escribe titulo, texto y adjuntos desde el primer boton.
  2. Ver buzon: abre el reporte con la imagen y el detalle.
  3. Limpia cuando quieras: usa "Borrar archivo" para reiniciar todo el flujo.
