¿Como funciona la pagina?

Este flujo toma tu tabla, prepara la seleccion y te deja enviar el video.

  1. Agrega la tabla: usa la tarjeta de arriba para cargar la informacion base.
  2. Revisa el conteo: valida el total detectado antes de continuar.
  3. Envia video: cuando se habilite, haz clic para finalizar el envio.
  4. Limpia cuando quieras: usa "Borrar archivo" para reiniciar la seleccion actual.

Pega aca la tabla

Copia las celdas desde Excel/Sheets y pégalas aquí (Ctrl+V). La primera fila debe ser el encabezado.
