¿Como funciona la pagina?

Este flujo adapta imagenes y genera un ZIP listo para descargar.

  1. Sube archivos: usa la tarjeta de subir o arrastra imagenes/ZIP al area de carga.
  2. Revisa el conteo: valida cuantas imagenes y ZIP detecto el sistema.
  3. Procesa y descarga: cuando "Descargar ZIP" se habilite, haz clic para generar el archivo final.
  4. Limpia cuando quieras: usa "Borrar archivo" para reiniciar la seleccion actual.
